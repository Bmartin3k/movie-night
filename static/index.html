    Who's rating?

    This device remembers who you picked. 🔒 people need their PIN once per device. You can only change your own ratings; for others you can add a first rating, not change one.

    Settings

    API keys and connections. What you save here takes over from the .env file straight away, no restart. Saved keys are never shown again, only their last 4 characters; leave a key box empty to keep it. They're kept in data/settings.json (owner-only, not in backups). Changing a server URL needs its key typed again. Set a password at the bottom so only grown-ups can change these.

    Household

    Everyone who rates movies. "Also known as" is a person's Emby / Jellyfin / Plex user name or Netflix profile name, so imported history is credited to the right person. 🔑 PIN: picking that person in Who's rating? asks for it once per device, so nobody else can change their ratings. Set a kid's age-rating limit, and any suggestions that include them stay within it (US MPA ratings from TMDB; movies with no US rating are left out). With a birthdate, imported Emby / Netflix / CSV viewings from before "count history from age" don't count for that person.

    Names from Emby / Jellyfin / Plex / Netflix not linked to anyone

    Link each one to a person (e.g. Emby user "jsmith" is Jane), or add them as a new person. Movies watched by an unlinked name are kept out of everyone's suggestions, to be safe.

    Import Netflix history

    1. On netflix.com: Account → Profiles → pick a profile → Viewing activity
    2. Scroll to the bottom and click Download all. You'll get NetflixViewingHistory.csv.
    3. Upload it here. Do each profile separately.

    TV episodes are skipped. Movies are matched to TMDB and land in To rate with their Netflix watch date. Anything already rated or already queued from Emby is not duplicated.
